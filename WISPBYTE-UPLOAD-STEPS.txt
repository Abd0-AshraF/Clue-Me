Clue Me — Wispbyte upload checklist
=================================

1) Upload the ZIP file to Wispbyte.
2) Startup command: npm start
3) Node version: 20+
4) Do NOT set PORT manually.
5) Add the variables from WISPBYTE-SECRETS.txt
6) Restart after saving variables.
7) Hard refresh the browser after deploy.

Important variables you must fill:
- PUBLIC_URL
- DATABASE_URL
- DISCORD_CLIENT_ID
- DISCORD_CLIENT_SECRET
- DISCORD_REDIRECT_URI
- DISCORD_DOMAIN_VERIFICATION
- DISCORD_SERVER_INVITE_URL

Discord server button:
- It appears on the home page next to Login.
- It only appears when DISCORD_SERVER_INVITE_URL is set.
